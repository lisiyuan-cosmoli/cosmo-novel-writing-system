# AI 腔指纹表（母版通用层）
#
# 这里只收**跨模型稳定**的表达。它们不是"写得不好的词"，是模型默认输出的指纹：
# 中文小说语料里网文与翻译腔占比很高，各家模型的预训练语料高度重叠，
# 加上偏好训练都朝"生动、有画面感、有节奏"收敛，于是不同模型产出同一批搭配。
#
# 格式：一行一条。#类别 开一个新类别。以 # 开头的其他行是注释。
# 条目按**正则**处理，写成搭配而不是单字——「一抹」误报率极高，「一抹笑意」不会。
#
# 三层关系：
#   本文件            母版通用层，随 sync 更新，不要在项目里改
#   AI腔词表_本项目.txt  项目自己积累的，主要是你实际用的那个模型的尾巴
#   允许AI腔.txt       本书有意保留的豁免，写明理由
#
# 报告按类别分组。它只报命中和行号，不打分、不拦提交。
# 网文题材会天然命中「动作套路」与「氛围套路」里的一部分——那是题材语汇，
# 不是缺陷。用 允许AI腔.txt 豁免，不要因此删掉母版条目。
