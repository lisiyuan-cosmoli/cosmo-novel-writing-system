# 07 章节卡模板

> 复制本文件到 `06_归档/章节卡_K0001.md`，把永久 ID 与展示章号改成本章值。
>
> 4.0 起，方向在弧卡里由作者批准，章节卡只落实这一章：三拍、必须出现的信息、知情变化和连续性约束。开篇、弧末高潮或出现新分歧时，把「方案来源」写成「本章比较」，并在下面写出两个走向。
>
> 正式读取包会校验本卡的结构、永久 ID、展示章号与必填内容。程序无法证明文字由作者亲手填写，只能记录来源与代拟标记。提交前核对可以在开写时留空，进入候选提交前必须全部完成。3.x 的旧卡继续按旧结构通过，不用改写。

「所属弧与批」写弧卡编号与批次，例如 A02 ／ K0019-K0021。逐章写作的开篇或高潮章写「A01 ／ 逐章」。

创作模式沿用已批准的读者引擎卡。通用模式按本书期待发展关系、认识、处境或体验；不强补对手、升级与危机。

## 三拍 🔒

| 开头兑现（上一章钩子） | 中段新麻烦或新回报 | 章末钩子（正文里已发生的事实或决定） | 钩子类型 |
|---|---|---|---|
| | | | |

钩子类型只能是：新信息、危险逼近、关系变化、选择当口、身份揭露、兑现在即、弧末收束。弧末收束只用于弧卡范围的最后一章；其他章确需安静收尾时，在类型格写明（理由：…）。

三拍表头沿用旧格式。通用模式可分别写承接、认识或体验的发展、自然落点；新发现记「新信息」，关系深化记「关系变化」。安静收束可用「弧末收束（理由：本章体验已完整）」，不要求改成悬崖式结尾。升级对抗模式按本书引擎安排兑现与回报。

落点须能在正文中找到依据，可以是事件、决定或认识变化，不用作者提问代替正文。“他究竟是谁？”这类作者提问不算。
