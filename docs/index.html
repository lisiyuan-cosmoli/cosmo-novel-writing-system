阶段审查

三章一小审，
十二章一大审。

写得越顺，越容易跑偏。COSMO 按实际定稿的章节计数，到点提醒审查：小审查关注最近几章的阅读体验，大审查检视整个阶段的结构是否立得住。

审查从读正文开始，再与你交流。确定的调整写回原大纲与章卡，后续章节直接依照执行；决定维持原计划，也要写明理由。

看审查如何改变后续章节 ↗

大审查包含当次小审查。程序负责提醒与记录，阅读和判断由你与 AI 完成。审查不是给小说打分。

常见问题

开始之前，
你可能想知道。

可以在这个网站上直接写小说吗？

不可以。本站只做介绍。起草、研究与改稿由你使用的 AI 工具完成，流程由本地 Python 工具执行。核心脚本可以离线运行；AI 服务是否联网、如何处理资料，取决于你选择的工具。

需要付费吗？token 消耗如何估算？

COSMO 免费开源，不内置任何付费 API，也不会代你调用模型。你使用的 AI 工具如何计费，以该服务的规则为准。

token 用量难以精确预估：同一段文字在不同模型下的分词结果不同，带入的资料量和交流轮数也会影响消耗。系统中的字符预算只用于控制读取包的资料量，并非 token 或费用上限。建议先试写一两章，以实际账单为准。

除了 Codex，还能使用哪些 AI 工具？

只要能打开整个项目文件夹、读写文件并运行命令，即可使用。以下工具可供参考，选择熟悉的一种即可。

桌面工作区：WorkBuddy；Claude Code 同时提供桌面、编辑器与终端入口。

编辑器内代理：Cursor Agent、GitHub Copilot（VS Code 代理）、Cline。

命令行工具：Codex CLI、Claude Code、Gemini CLI；Cline 也提供命令行入口。

仅在聊天中上传附件无法使用。使用云端工作区时，请确认完整项目可以导出或同步回本地；使用 Claude 的其他文件工作模式时，请单独确认它能读取整个项目、运行命令并保存修改。

以上均为官方资料链接，核对日期为 2026-09-23。名单不代表已逐一验证兼容，也不构成写作质量评价。本版仅在 macOS 上完成验证，需要 Python 3.9 或以上；工具本身支持 Windows，不代表 COSMO 已支持原生 Windows。请先用独立副本试用。

有英文网站，系统可以全英文使用吗？

暂不支持。英文网站是介绍内容的翻译，系统内核、模板与使用文档仍以中文为主，不承诺完整的英文写作体验。

项目许可允许改造为其他语言，但需要同步适配提示词与模板、中文路径与字段解析，以及语言检查，并用示例项目完整验证。

不同类型的故事，可以选择不同的写法吗？

可以。新书默认使用“通用”模式，围绕读者期待与阶段发展进行检查，适合关系、成长、日常等题材，也允许故事自然收束。选择“升级对抗”模式后，才会额外核对对手、升级与爽点兑现。

从旧版本升级的作品不受影响：旧的设定卡沿用原有解释，未启用该功能的旧书无需补填。

三章一审，会不会把故事写得太赶？

不会。审查关注的是阅读动力，节奏舒缓的章节同样可以通过新的感受、关系变化或信息推进故事。先指出具体哪一段失去吸引力，再决定是否提速，不会机械地堆砌冲突和反转。

程序只负责提醒审查到期，结论由你与 AI 阅读后得出。有效的叙述不必为了填表而修改。

每十二章都必须研究榜单作品吗？

不必。榜单研究是可选项，不开展时写明理由即可。如需开展，由具备联网能力的 AI 工具挑选同类作品，阅读可合法访问的连续正文，记录来源、日期与阅读范围，并提炼可供本书借鉴的通用方法。

访问受限时如实记录实际阅读范围，不会自动追加下一轮的补查任务。COSMO 的工具本身不联网，也不会把作品简介当作已读正文。

导入文风样本，会直接修改正式设定吗？

不会。选定的样本先进入候选区：开书阶段使用 INIT 候选，已开书的修订使用 REVISE 候选。完成样本分析并经你确认后，才会更新正式文风样本。

旧书需要补做开书流程时，可以明确选择 INIT；两种候选同时存在时，工具会要求先选定本轮处理的对象。文风、题材插件与创作模式相互独立，分别选择。

候选存根和备份，分别保存什么？

6.0 在章节成功提交后，会将本次候选移入存根目录并告知位置。提交期间新保存的内容可在此核对；存根不会自动成为正式稿，也不能沿用此前的确认。

常规备份只保存当前有效内容，不包含候选、存根、读取包与事务历史。重要的未采用内容请另行保存。保存中断时的现场备份只能保留现场，不保证能恢复出前后一致的作品，恢复前请先核对记录。

更换题材或 AI 工具后，还能继续写吗？

可以。约定与进度都保存在本地文件中，换用其他支持本地文件操作的 AI 工具，同样可以接续。4 类题材插件按需启用，包括悬疑推理、言情情感、科幻奇幻与网文连载，也可以不安装。

更换工具后，请让新的 AI 先读取本书入口与当前状态，后续取舍仍以你确认过的内容为准。

更新系统，会覆盖已写的内容吗？

不会。开新书时复制预留的空白模板或重新下载即可，已有作品继续使用原文件夹。更新前，系统会核对安装时的基线记录；遇到无法识别的差异或本地修改，默认停止，已识别的书内定制按保留规则处理。

系统更新不会替你采用新的故事方案，也不会改动已写好的内容。
