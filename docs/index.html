6.0 / 按作品选择创作方式

读者往下读的动力，
要一段一段地看。

新书默认通用模式，围绕阅读期待和阶段发展，可以写关系、认识与体验，也允许自然收束。选择升级对抗模式后，再核对对手、升级和爽感兑现。没有模式字段的旧引擎卡沿用原解释；未启用引擎的旧书不因升级被迫补卡。

默认每批三章，也可一章一批；批次上限可在项目配置中调整，最多五章。每三章回看近期体验，每十二章或弧末复盘阶段结构，写出加强措施或保留原规划的理由。先读正文，再与作者交流；相关榜单研究可选，不做说明理由，同轮不重复访谈。

AI 需能读写文件和运行命令；如果拖入后尚未打开项目，选择该文件夹作为工作目录即可。运行环境与其他工具见 使用说明。

使用前，了解几件事

把能力与边界
说清楚。

这是一个可以在线写小说的网站吗？

本页用于介绍系统。正文起草、研究与改稿由你使用的 AI 助手完成，Python 工具负责本地流程。系统核心脚本可以离线运行；AI 服务如何联网、如何处理资料，取决于你选择的工具。

会调用付费 API 吗？token 消耗怎么估算？

系统没有内置付费 API，也不代你调用模型。使用外部 AI 助手时，是否收费以及如何计费，由你选择的服务决定。

即使处理相同文字，模型的分词方式不同，token 数也可能不同。带入的上下文、读取档位和来回讨论的次数都会影响消耗。系统中的字符预算只用于控制整理出的资料量，不是 token 或费用上限；实际用量和费用以所用服务为准。

除了 Codex，还可以考虑哪些 AI 工具？

可以继续用熟悉的 Codex，也可以从以下工具中选择一个试用。它们的常见入口不同，部分工具同时提供多种界面。

桌面工作区：WorkBuddy；Claude Code 也提供桌面、编辑器与终端入口。

编辑器内代理：Cursor Agent、GitHub Copilot（VS Code 代理）、Cline。

命令行工具：Codex CLI、Claude Code、Gemini CLI；Cline 也有命令行入口。

目前仅在 macOS 上完成验证，需要 Python 3.9 或以上。Windows、Linux 与 WSL 等其他环境尚未验证；如需使用，请自行适配并测试，确认文件保存、备份和恢复正常后再用于正式作品。由代理检查环境。所用模式需能读取整个项目、运行命令，并保存修改。仅上传聊天附件不够；使用云端工作区，还需确认完整项目怎样导出或同步回来。若使用 Claude 的其他文件工作模式，请单独核对这些能力。

以上链接为官方资料，核对日期为 2026-09-23。名单不代表本系统已逐一验证兼容，也不评价写作质量。先用独立副本试用；工具支持 Windows 不代表本系统已支持原生 Windows。不同工具与模型的费用和 token 用量仍需分别核对。

有英文网站，是否可以全英文使用系统？

网站提供完整的中英文介绍，系统内核、模板和使用文档仍以中文为主。英文网站不代表内核已英文化，也不承诺完整的英文操作体验。

可以按项目许可自行改造成其他语言，但需要同步适配提示词与模板、中文路径和字段解析，以及语言检查，并用示例项目验证。

三章一次审查，会不会把所有故事都写快？

审查关注阅读动力。舒缓的章节也可以通过新的感受、关系变化或信息提供推进。应先解释具体段落哪里失去吸引力，再决定是否加速，避免机械增加反转和冲突。

程序提示待办，审查结论由作者与 AI 阅读后形成。没有必要为了填满表格改掉有效的叙述。

需要每十二章都研究榜单吗？

榜单正文研究可选，不开展时说明理由。若开展，由具备浏览能力的 AI 助手选择同类作品，实际阅读合法可访问的连续正文，并记录来源、日期与阅读范围，提炼可用于本书的通用方法。

访问受限时如实记录实际范围和补查条件，不自动新增下轮补查任务。工具本身不会自动联网，也不会把简介当成已读正文。

导入文风样本，会直接改掉正式设定吗？

选定的样本先进入候选：新书开书使用 INIT，已开书修订使用 REVISE。补齐样本分析，再按原有流程检查并批准同一摘要，正式样本才会更新。

旧书补做开书时可明确选择 INIT；两种候选并存时，工具会要求先选清本轮处理的对象。文风档、题材插件与创作模式分别选择。

候选存根和备份，各自保存什么？

6.0 成功提交章节后，将候选保留到存根目录，并在结果中给出位置。提交期间又保存的内容可以在那里核对；它不会自动成为正式稿，也不能沿用原先的批准。

常规备份保存当前有效内容，不含候选、存根、读取包和事务历史。重要的未采纳内容需另行保存。中断事务的现场备份只能保住现场，不保证恢复出自洽作品；恢复前仍须核对记录。

换题材、换 AI 工具，还能继续吗？

系统通过本地文件保存约定与进度，可以交给兼容本地文件工作的 AI 助手继续。按需启用 4 类题材插件，包括悬疑推理、言情情感、科幻奇幻和网文连载，也可以不装插件。

更换助手时重新读取本书入口与当前状态，后续取舍仍以作者确认的内容为依据。

更新系统，会覆盖书里的内容吗？

开新书时，可以复制预先保留的空白模板，也可以重新下载系统。已有作品继续使用原文件夹。同步会核对已记录的安装基线；遇到未知差异或本地修改时默认停止，识别出的书内定制按保留规则处理。

系统更新不代表采用新的故事方案，也不替作者完成内容修订。

目前验证到了什么程度？

6.0 发布自测为 446 / 446 项通过，覆盖初始化、读取包、提交、修订、阶段审查记录、同步与恢复等软件流程。

软件检查通过不能证明小说好看。人物、语言和阅读动力仍需要实际审阅与读者反馈。详细范围见交付验收报告与已知限制。
