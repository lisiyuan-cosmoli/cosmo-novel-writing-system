## 推荐方向

通常给两三条有差异的路线，可结合多个来源，也可全部否决。

| 路线 | 作者与具体作品 | 来源、版本及实际阅读范围 | 借鉴的叙述距离、节奏、细节或对白 | 适合本书的理由 | 局限与不宜照搬的部分 |
|---|---|---|---|---|---|
| | | | | | |

未核实的作品信息标为未核实。只读过简介时不能声称已经分析正文文风。可以推荐当代或经典作家供阅读比较；试写只采用明确的通用技法，不复刻某位作者的独特声音，不复制原句。

先根据偏好缩小方向，再决定是否需要完整候选。正式采用的正样本仍满足现有开书标准。不要为了制造差异，把每个维度都推到极端；动作、对话和沉淀场景可各有变化。
