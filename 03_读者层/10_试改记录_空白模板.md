# 试改记录空白模板

这是空白模板，复制到本轮探索目录后填写。它不记录真实反馈，不作为强制提交表。作者记录和给读者的空表分开保存，只把最后一节单独复制给读者。模板会随系统更新，勿在原件填写作品资料。

## 给读者的空白问题表

只将本节和匿名正文交给读者，不附上面的作者记录。先读一版，填写即时反应，再读另一版。可以停读，也可以认为两版一样或都不好。

| 基本信息 | 内容 |
|---|---|
| 读者代号、套别与章节 | |
| 是否读过此稿或知道剧情 | |
| 本次先读的版本编号 | |

每版各填一份。

| 即时反应 | 内容 |
|---|---|
| 版本编号 | |
| 最清楚地记住了什么 | |
| 你怎样理解人物正在做的事或这段相处 | |
| 哪里想跳过、回看或没有看懂，请指出位置 | |
| 有没有哪句话不像这个人物会说或会想的 | |
| 读完想继续看什么，或已经不想继续 | |
| 未读完时停在哪里及原因 | |
| 若有记录，实际阅读用了多久 | |

两版读完后再填。
