# 05 人物声音

> 这张表回答一件事：**这句话为什么只能是他说的。** 填了才进读取包。
>
> 故事圣经的人物档案管“他是谁、他要什么”，那些是剧情栏。这张表只管**嘴**。
> 一个人可以有满满一页档案，写出来照样跟别人分不开——分不开，是因为档案里没有一条是关于他怎么说话的。
>
> 新书在开书阶段跟读者引擎卡一起填；旧项目同步后是空模板，**空模板不启用**，不影响既有的包与提交。

## 怎么定

**门槛**：出场达到 3 章的角色就要有一行。路人不必。

**每人四行，四行全是关于嘴的：**

| 行 | 写什么 | 反例 |
|---|---|---|
| 句子倾向 | 长还是短，一句说完还是碎着说，什么情况下会变 | ✗「说话很有条理」——看不出长短 |
| 语言习惯 | 一个**能被指出来**的说法：爱反问／爱叫人／爱重复对方的词／先抛钩子再揭晓 | ✗「幽默风趣」——指不出是哪一句 |
| 绝不会说 | 一句他不会说的话。**划边界比给特征管用**，违反了当场就看得出来 | ✗「不会说谎」——那是人品不是嘴 |
| 变化线与锚 | 从哪一弧变到哪一弧，**外加一个明确不许变的量** | ✗ 只写变化不写锚——见下 |

**为什么第四行必须带锚。**
人物声音会随剧情变，但变化分三种：有意的成长、无意的漂移、功能塌掉。
光看“变了多少”分不开——句子变短可能是这个人变狠了，也可能是写着写着把他写没了。
分开它们的只有锚：**指定一个不许变的量，变了其他项仍然是他；没有锚，任何走样看起来都像是有意的。**

锚要挑这个人最像他自己的那一项，写成可核对的形式（“语气词密度不低于 0.12”“称谓密度不低于 0.6”“每次出场至少带一条有来源有时间的消息”）。

## 全书底噪

声音分得开，不等于像活人。下面两项是“像不像真人在说话”，与人物多少无关：

| 项 | 要求 | 说明 |
|---|---|---|
| 语气词密度 | 目标不低于 0.15 句/次 | 吧、呢、啊、嘛。低于 0.10 时全书会变成一片书面语，谁都不像在说话 |
| 迟疑与碎句 | 目标不低于 0.08 句/次 | 打断自己、说半句改口、重复。人物要被允许把话说坏 |

这两项靠动笔时做，不靠这张表。表只管人跟人分不分得开。
