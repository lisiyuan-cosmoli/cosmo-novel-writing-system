# 正文存放

正文文件使用四位永久 ID 命名，例如 `K0001.md`。展示章号发生变化时，文件名保持不变。

每份正文开头保留一行机器元信息。

```text
<!-- 永久ID:K0001 | 展示章号:1 | 视角:XXX | 字数:2800 | 状态:已定稿 | 定稿日期:YYYY-MM-DD -->
```

状态取值包括初稿、已定稿、待返工和已废弃。

永久 ID 必须与文件名一致，展示章号、视角和状态与大纲对应；字数必须等于实测净字数。每个必需字段只出现一次。日期可选。`doctor`、章节提交与全局修订共用身份检查；调序时同步修改正文头及已有章卡的展示章号。

已显式迁移项目中，归档基线之前的旧永久 ID 可以保留原来缺少的展示章号、视角或字数字段，体检给出提示，已有字段仍须正确。新章和本次修订过的正文必须补齐上述字段；修改展示顺序不会扩大旧章兼容范围。

## 正文洁净

- 文件头只放永久 ID、展示章号、视角、字数、状态和日期
- 正文不出现工作模式、版本、候选走向或流程标记
- 创作记录放入运行层、检查层或归档层
- 对外导出时移除文件头

后续读取只把已定稿章节当作已经成立的正文事实。
